# B1: Relatório gerencial (Granel, ts >= 2026-06-01)

## Índice criado
db.movimentacoes.createIndex({ classe: 1, ts: 1, terminal: 1, peso_kg: 1 })
Os dois primeiros campos servem ao $match (igualdade em classe, range em ts) e os
dois últimos (terminal, peso_kg) são os únicos campos usados no $group, o que torna
a consulta coberta.

## Pipeline
db.movimentacoes.aggregate([
  { $match: { classe: "Granel", ts: { $gte: ISODate("2026-06-01T00:00:00Z") } } },
  { $group: { _id: "$terminal", total_mov: { $sum: 1 }, peso_total: { $sum: "$peso_kg" },
              peso_medio: { $avg: "$peso_kg" }, maior_peso: { $max: "$peso_kg" } } },
  { $sort: { peso_total: -1 } },
  { $limit: 3 },
  { $project: { _id: 0, terminal: "$_id", total_mov: 1, peso_total: 1, peso_medio: 1, maior_peso: 1 } }
])
